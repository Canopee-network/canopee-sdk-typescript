# Canopee SDK — TypeScript

Client SDK for a [Canopee](https://github.com/Canopee-network/canopee) node's
Unix socket: identity, storage, user records, devices, pairing, DHT, pub/sub
and capabilities — API-for-API parity with the Rust `canopee-sdk` crate.

## Install / build

```sh
npm install
npm run build     # TypeScript → dist (CommonJS + .d.ts)
npm test          # builds and runs golden-vector + framing tests
```

Requires Node ≥ 18. No runtime dependencies.

## Quick start

```ts
import { CanopeeClient } from 'canopee-sdk-typescript';

const node = new CanopeeClient(); // $CANOPEE_APP_ROOT/.canopee/node.sock, else ~/.canopee/node.sock

const id = await node.put([104, 105]);                 // store a blob
const bytes = (await node.get(id)).payload.data;        // read it back
await node.setName(id, 'hi');
const list = await node.list();                         // ObjectInfo[]
const status = await node.status();                     // { identity, objects, peers }
await node.addDevice('12D3KooW...', 'phone2');
await node.removeDevice('12D3KooW...');

for await (const msg of node.subscribe('app-topic')) {
  console.log(msg.topic, msg.data);
}
```

## API

Every method mirrors the `NodeCommand`/`NodeResponse` pairs of the Rust SDK:

- **Storage**: `put`, `putObject`, `concat`, `get`, `list`, `deleteObject`,
  `setName`, `exportObject`, `importObject`
- **Runtime/identity**: `status`, `identity`, `shutdown`, `dhPublicKey`,
  `saveProfile`, `loadProfile`, `saveContactList`, `loadContactList`,
  `saveHomeIndex`, `loadHomeIndex`, `setHomeEntryShared`, `exportIdentity`,
  `importIdentity`
- **Network/user records**: `publishPointer`, `publishAppPointer`,
  `resolveAppPointer`, `resolvePointer`, `claimUsername`, `resolveUsername`,
  `showUsername`, `resolveProfile`
- **Devices/pairing**: `device`, `deviceList`, `resolveOwnerDevice`,
  `addDevice`, `removeDevice`, `initiatePairing`, `completePairing`,
  `syncFromPeer`, `syncDeviceList`
- **Networking/DHT**: `dial`, `listenViaRelay`, `publish`, `peers`,
  `relayReservations`, `findProviders`, `fetchObject`, `announce`,
  `putObjectPublic`, `shareObject`, `subscribe`
- **Capabilities**: `grantCapability`, `listCapabilities`,
  `revokeCapability`, `checkCapability`, `checkAccess`
- **Serve sessions**: `startServeSession`, `stopServeSession`

Byte arrays are plain `number[]`. The node replies `Error` → throws
`CanopeeError`; an unreachable socket → `NodeNotRunningError`.

Typed model lives in `src/types.ts` (camelCase); `src/codec.ts` is the bincode
1.x legacy codec and the exact `NodeCommand`/`NodeResponse` schemas.

## Wire contract

Frame = `u32 LE length` + payload, over a Unix socket. Payloads are **bincode
1.x legacy**: little-endian fixints, `u32` enum tags, `u64` length prefixes,
`Option` = one tag byte, fixed arrays raw, map keys sorted. The golden fixture
`tests/fixtures/golden.json` (generated by `canopee-sdk`'s
`tests/golden_vectors.rs`) pins every encoder/decoder to the exact bytes the
node speaks; `npm test` re-asserts all 138 vectors in both directions.
